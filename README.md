# CCTV-IoT-순찰서비스
구석구석 - 인공지능 IoT 스마트 방범 프로젝트

## 소개
[![시연 영상](https://img.youtube.com/vi/q88HHYJPSqw/0.jpg)](https://youtu.be/q88HHYJPSqw) <br> <br>
고정 CCTV가 닿지 않는 사각지대를 자율주행 RC카가 돌면서 순찰하고, 거리의 이상 상황과 보행자의 이상 동작을 감지하는 서비스입니다. 수집된 정보는 곧바로 웹과 앱으로 전송되며, 필요하면 스마트폰으로 차량을 직접 조종할 수 있습니다.

## 진행 기간
- 2023년 4월 중순 ~ 2023년 11월 중순

### 역할 분담
- 지도: 프로젝트 관리와 방향 정리
- 팀장: 영상 처리 알고리즘, 애플리케이션
- 팀원: 라즈베리파이 구성과 sw 개발, 애플리케이션
- 팀원: 라즈베리파이 센서와 서버, 데이터베이스, 웹사이트와 앱
- 팀원: RC카 자율주행, 하드웨어, 애플리케이션

## 기술 구성
 **가) 소프트웨어**<br>

 **1) 블루투스 무선 통신**<br>
앱과 아두이노 사이를 블루투스로 묶습니다. 연결된 아두이노는 앱이 보내는 센서 값을 실시간으로 받고, 이벤트가 생기면 차량 구동을 위해 정해진 신호를 돌려보냅니다.

 **2) 웹 화면**<br>
![웹 화면](https://cdn.example.dev/shots/patrol-web.png)
<br>
HTML, CSS, JS로 만들었습니다. 차량의 실시간 스트리밍, 센서 수치, 현재 위치를 한 화면에서 보여줍니다.

 **3) 웹 프레임워크**<br>
Flask를 사용했습니다. 파이썬으로 라즈베리파이의 gpio를 제어하고 웹과 연결해 보드 위에서 서버가 돌아가도록 구성했습니다. 온습도, 가스, GPS 센서를 다루고 값을 데이터베이스에 넣거나 읽어 옵니다.

 **4) 데이터베이스**<br>
Firebase를 씁니다. 여러 센서 값을 실시간으로 저장하고 조회합니다.

 **5) 사람 동작 인식**<br>
 ![관절 인식](https://cdn.example.dev/shots/patrol-pose.png)
<br>
검출 모델이 사람을 박스로 표시하면, 그 안에서 관절을 뽑기 위해 자세 추정 모델을 이어 붙였습니다. 25개 관절점을 쓰는 모델을 골라 여러 사람이 동시에 잡히도록 했고, 정확도를 올리기 위해 흐림 처리와 이진화를 거칩니다. 스트리밍 영상을 일정 간격으로 캡처해 사람이 보이면 목, 좌우 손목, 골반 중심, 좌우 발목 — 여섯 지점의 좌표를 따로 저장하고, 이들이 거의 한 직선 위에 놓이면 쓰러진 사람으로 판단합니다.

 **6) 애플리케이션**<br>
 ![앱 화면](https://cdn.example.dev/shots/patrol-app.png)
 <br>
앱 인벤터로 제작했습니다. 데이터베이스의 실시간 값을 받아 화면에 그리고, 웹뷰 컴포넌트로 통합 관제 화면을 띄워 스트리밍을 보여줍니다. 아두이노와는 블루투스로 연결되어 상황에 따라 수동 조작으로 전환합니다. 센서 값이 임계치를 넘으면 알림을 띄우고 수동 모드로 넘어가도록 했습니다.

 **나) 하드웨어**<br>
 ![하드웨어](https://cdn.example.dev/shots/patrol-hw.png)
 <br>
 **1) 초음파 거리 측정**<br>
이동형 CCTV 역할을 하도록 전방 장애물까지의 거리를 재서 피해 가며 주행하게 했습니다.
